## iOS MVC Networking ##

A simple iOS app built with UIKit & Storyboard using the MVC architecture pattern. It fetches and displays a list of tourist places in the Malang-Batu area from a Firebase-hosted JSON endpoint, with image loading and caching powered by Swift Package Manager dependencies.
